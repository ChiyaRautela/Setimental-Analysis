Built a machine learning model to classify movie reviews as positive or negative.
Used the IMDB dataset with 50,000 labeled reviews for training and testing.
Achieved 85% accuracy using a logistic regression classifier.
Applied text preprocessing techniques like tokenization, stopword removal, and TF-IDF vectorization.
Utilized Pandas and NumPy for data cleaning and manipulation.
Employed Scikit-learn for model building, training, and evaluation.
Resulted in an effective tool for understanding audience sentiment based on written feedback.
